🚀 Tayang

Selama Bapak belum mengirim file di bawah ini ke Bowo dan belum mengetuk Izinkan di kartu unggah, situs publik TIDAK berubah sama sekali.

Apa yang berubah

    File baru (foto/logo/video)

      Cara tayang

      1. Unduh semua file di atas.
      2. Kirim file-file itu ke Bowo di chat (site.json + foto-foto baru).
      3. Bowo merakit ulang situs + mengunggah; Bapak ketuk Izinkan di kartu unggah.
      4. Bowo memeriksa situs live sudah berubah, baru melapor selesai.
